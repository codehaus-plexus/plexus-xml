## Plexus XML Utilities

A collection of various utility classes to ease working with XML in Maven 3.

This is the `3.x` line. It requires Java 8 or later and has no dependencies. Its XML classes (in
`org.codehaus.plexus.util.xml` and `org.codehaus.plexus.util.xml.pull`) are the ones that
[`plexus-utils`](https://github.com/codehaus-plexus/plexus-utils) 3 bundles, extracted into their own library. See the
[README](https://github.com/codehaus-plexus/plexus-xml/tree/3.x#readme) for when to use it. The
[Javadoc](./apidocs/index.html) is the reference for the classes.
